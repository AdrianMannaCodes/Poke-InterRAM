Question 3: "В каком ряду во всех словах пишется одна и та же буква?"

Options:
1) ко..ьба, ука..ка, про..ьба (косьба, указка, просьба -> с / з / с)
2) коро..ка, ги..кий, ру..ка (деревьев) (коробка, гибкий, рубка -> везде 'б')
3) кры..ка, мо..ка, сне..ный (крышка, мошка, снежный -> ш / ш / ж)
4) сапо.. , вра.. , пото.. (сапог, враг, поток -> г / г / к)

Answer: Вариант 2: "коро..ка, ги..кий, ру..ка (деревьев)" (буква 'б' во всех словах: коробка, гибкий, рубка)
