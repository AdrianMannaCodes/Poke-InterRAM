## Chat Q&A

Question: "Кто создал карту, изображенную на рисунке"

Options:
1. Дж. Кук
2. Аристотель
3. Х. Колумб
4. Птолемей

Answer: 4. Птолемей (карта мира Птолемея).

Question: "Какой материк был открыт во время экспедиции Ф. Беллингаузена и М.Лазарева?"

Answer: "Антарктида"

Question: "Этот землепроходец положил начало географическим открытиям в Сибири в 1581г."

Answer: "Ермак (Ермак Тимофеевич)"

Question: "Иван Москвитин что открыл"

Answer: "Вышел к Охотскому морю, открыл Сахалинский залив и Шантарские острова"

Question: "Какую из крайних юго-западных точек материка Африка проплыл в ходе своей экспедиции в Индию Васко да Гама в 1498г.?"

Answer: "Мыс Доброй Надежды"

Question: "Определите по карте, кто из великих путешественников плыл по этому маршруту (маршрут из Венеции через Азию)?"

Answer: "Марко Поло"

Question: "Во время экспедиции из России в Индию Афанасий Никитин написал книгу о своем путешествии. Как она называлась?"
